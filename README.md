# ToDo
This application allows the user to perform CRUD operations on tasks that they create, involving a priority level, title, description, and completion status.
Usage is simple as the user must simply double click the exe downloaded from the releases section, and navigate through the CLI prompts.

#Specifications
Created using C++ in Visual Studio Code utilizing standard C++ libraries. 
This application utilizes text files to store the tasks the user creates, and when running will use a combination of an unordered map and buckets for quick lookups and functionality.
